# Gavel - Semester Project 2

A student-only auction marketplace built with vanilla TypeScript, Tailwind CSS, and the Noroff Auction House API v2. Built with Vite.

Course: Semester Project 2 (Noroff)  
Author: Pål Omland Eilevstjønn

## Features

- Browse, search, and filter active auction listings
- View listing details, image galleries, and full bid history
- Register and log in with a `@stud.noroff.no` email
- Place bids on active listings with virtual credits
- Create, update, and delete listings
- Manage profile avatar, banner, and bio
- Track credit balance, active bids, and saved watchlist

## Running locally

You need Node.js (20+) and a `@stud.noroff.no` email to register an account.

```bash
git clone https://github.com/DYNNIwav/gavel.git
cd gavel
npm install
npm run dev
```

Then open the URL printed in the terminal.
